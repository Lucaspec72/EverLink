EVERLINK RELAY - BUILD INSTRUCTIONS
======================================

WHAT THIS IS
------------
The ESP32 firmware half of EverLink. Reads the packet protocol from EverLink
Host over serial and re-emits it as a real USB Xbox 360/XInput controller,
so the console sees a genuine gamepad plugged in.

This REQUIRES a native-USB-capable board - an S2, S3, or P4-family ESP32
(anything with a real USB OTG peripheral, not just a USB-serial bridge
chip). Plain ESP32 and C3-family boards cannot run this firmware's USB
output stage; Host's device list already flags this ("USB Output:
Unsupported") for any board it detects as incapable.

It also responds to an identification ping (see ../EverLink_Protocol.md) so
Host's device scan can recognize this board as a genuine EverLink Relay
(rather than just any COM port), read its unique hardware MAC address for
stable device naming, and check its chip model. This uses the SAME
firmware binary across every board - no per-device editing needed, since
both the identity and chip model come from the hardware/SDK itself, not
from anything written into the code.

REQUIRED LIBRARY
-----------------
  ESP32XInput - provides the USB Xbox 360/XInput HID output. Install via
  Arduino IDE's Library Manager (search "ESP32XInput") or PlatformIO's
  lib_deps. This firmware calls ESP32XInput.begin(), .setButton(),
  .setHat(), .setLeftTrigger()/.setRightTrigger(), .setStickLeft()/
  .setStickRight(), .send(), .pollRumble(), and .ready() - if you're on a
  fork/version with a different API shape, the calls in "EverLink Relay.ino"
  are the ones that need matching up.

OPTION A: ARDUINO IDE (simplest to start with)
-------------------------------------------------
1. Install Arduino IDE (2.x): https://www.arduino.cc/en/software

2. Add ESP32 board support:
   - File > Preferences > "Additional Board Manager URLs" add:
     https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   - Tools > Board > Boards Manager > search "esp32" > install
     "esp32 by Espressif Systems"

3. Install the ESP32XInput library (Library Manager, see above).

4. Open "EverLink Relay.ino" in the Arduino IDE

5. Select your board and USB mode:
   - Tools > Board > ESP32 Arduino > pick your specific S2/S3/P4 board
   - Tools > USB Mode > "USB-OTG (TinyUSB)" (exact wording varies by
     board package version) - this is required for native USB HID output;
     the default "Hardware CDC and JTAG" mode will NOT work here
   - Tools > Port > select the COM port your board shows up on

6. Click Upload (arrow icon). If it fails to connect:
   - Hold the BOOT button on the board while upload starts, release once
     it begins writing (you'll see dots/progress in the output console)
   - Some S2/S3 boards need the cable plugged into the USB-OTG/native
     port specifically for upload, not a separate USB-UART port - check
     your board's silkscreen/documentation if upload doesn't work
